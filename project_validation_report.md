## Known Limitations

- This is a software model, not commissioning of a physical PLC or VFD.
- The E-stop is represented as a software interlock and is not a certified safety function.
- The conveyor sequence is intentionally single-product tracked; the baseline scenario spaces arrivals. A production system with close product spacing would need product tracking/queueing.
- Sensor and actuator models are low-order behavioral models, not hardware characterization.
- PID tuning is valid only for the stated first-order motor model and does not claim universal superiority.
- HMI is a Python-generated dashboard, not a vendor-certified runtime.
